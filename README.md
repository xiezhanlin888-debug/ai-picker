## v5.0 关键修复：数据层全面改用 JSONP

### 为什么之前一直刷不出行情

实测各接口的 CORS 响应头（模拟浏览器 Origin）：

| 通道 | Access-Control-Allow-Origin | 结果 |
|---|---|---|
| 新浪 `json_v2.php` num=100 | **无** | 浏览器判定跨域失败 |
| 新浪 `json_v2.php` num=80 | `*` | 偶发成功 |
| 新浪 `json_v2.php` page=5 | **无** | 失败 |
| 新浪 `jsonp_v2.php` | **`*`（始终）** | 稳定 |
| 东财 `ulist` / `kline` | 回显 Origin | 稳定 |
| 东财 `clist`（全市场） | 连接被重置 | 已下线 |

**新浪的 CORS 头是随机缺失的** —— 所以旧版靠 fetch 取数据时好时坏，浏览器里几乎必失败。

### 解决方案

**全部改用 JSONP**（`<script>` 标签加载，天生不受 CORS 约束）：

```js
// 新浪：回调名放在路径里
https://money.finance.sina.com.cn/quotes_service/api/jsonp_v2.php/<cb>/Market_Center.getHQNodeData?...
// 东财：标准的 cb= 参数
https://push2.eastmoney.com/api/qt/ulist.np/get?...&cb=<cb>
```

要点：
- 每次请求生成唯一回调名 `__jp<seq>_<rand>`，互不干扰，可并发 8 路
- 支持 `document.head` 的脚本注入 + 超时 + `onerror` 清理
- 非浏览器环境（Node 测试）自动降级回 fetch

### 同时修掉的隐藏 bug

旧版 `sinaSnapshot` 只要有**任何一页**返回条数不足就 `stop = true`，单页偶发失败会直接把快照截断成 100 只。现改为：失败页记为 `null` 并**最后统一重试**，全部拉完后按代码去重，只在连续两批全空时才停止。

## 严格尾盘策略（8 条硬规则）

默认开启，扫描时逐条硬过滤，宁缺毋滥：

| # | 规则 | 阈值 | 逻辑 |
|---|---|---|---|
| 1 | 时间 | 仅 14:30–15:00 下单 | 其他时段不看盘、不操作，避开早盘假信号 |
| 2 | 涨幅 | 主板 3%–5% | >5% 追高，<3% 无惯性；主板=沪60/深00，排除创业/科创/北交所 |
| 3 | 活性 | 近 20 日有涨停 | 有主力关注、有拉升记忆 |
| 4 | 量比 | ≥1 | 当天有人气，次日才有冲高动能 |
| 5 | 换手 | 5%–10% | 主力在场且未出货 |
| 6 | 市值 | 总市值 50–200 亿 | 大盘股拉不动，小盘股易爆雷 |
| 7 | 分时 | 站上分时均价（黄线） | 进场资金浮盈、无套牢盘 |
| 8 | 强弱 | 强于大盘 | 多头主导，溢价概率高 |

- 规则 4（量比）由东财 `ulist` 补全后过滤（新浪源无量比字段）。
- 规则 3（涨停）由日 K 线计算。
- 规则 7（分时均价）= 成交额 / 成交量。
- 弱势下跌日可能 **0 只入选**——这是策略正确行为（空仓观望），App 会友好提示而非报错。

设置页可开关「严格模式」与「交易时段闸门」（关闭闸门仅用于测试）。

## v4.0 核心：AI 智能体（Function Calling）

AI 不再是「你把数据喂给它」，而是**自己决定调用哪个工具去取数据、自己下单**。

内置 7 个工具：

| 工具 | 作用 |
|---|---|
| `market_overview` | 全市场涨跌宽度、情绪指数、板块强弱、成交额 |
| `capital_flow` | 主力资金净流入/流出前列 |
| `screen_stocks` | 按策略筛选 + 打分（已接入严格 8 规则） |
| `stock_detail` | 个股行情 + 均线 + 涨跌 + 波动率 + 回撤 + 回测胜率 |
| `get_account` | 模拟盘资产、现金、收益率、持仓明细、胜率 |
| `paper_buy` | 模拟盘买入（真实扣虚拟资金并记账） |
| `paper_sell` | 模拟盘卖出（止盈/止损/到期） |

### 全自动交易

首页「AI 全自动交易」→「▶ 让 AI 全自动执行」：

1. 分析大盘 + 主力资金
2. 按策略（严格 8 规则）选候选
3. 卖出已达止盈/破止损/隔日到期的持仓
4. 买入 1~3 只候选
5. 输出中文结论

设置页可开「启动时自动跑一遍」（每天一次）。`paper_buy/paper_sell` 受交易时段闸门保护。
