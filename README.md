# AI 选股 · 短线终端 v4.0

隔日短线量化选股 + **AI 智能体自主取数下单** + 实时日志 + 模拟盘复利，安卓 APK / PWA 双端。

## v4.0 核心：AI 智能体（Function Calling）

AI 不再是「你把数据喂给它」，而是**自己决定调用哪个工具去取数据、自己下单**。

内置 7 个工具：

| 工具 | 作用 |
|---|---|
| `market_overview` | 全市场涨跌宽度、情绪指数、板块强弱、成交额 |
| `capital_flow` | 主力资金净流入/流出前列 |
| `screen_stocks` | 按策略筛选 + 打分（4 种策略） |
| `stock_detail` | 个股行情 + 均线 + 涨跌 + 波动率 + 回撤 + 回测胜率 |
| `get_account` | 模拟盘资产、现金、收益率、持仓明细、胜率 |
| `paper_buy` | 模拟盘买入（真实扣虚拟资金并记账） |
| `paper_sell` | 模拟盘卖出（止盈/止损/到期） |

AI 会进行多轮推理：先看大盘 → 查资金 → 筛股 → 查详情 → 查账户 → 下单 → 输出理由。实测一次任务调用 **10 次工具**，全程约 56 秒。

### 全自动交易

首页「AI 全自动交易」卡片 → 点「▶ 让 AI 全自动执行」：

1. 分析大盘 + 主力资金
2. 按策略选出候选
3. 卖出已达止盈/破止损/隔日到期的持仓
4. 买入 1~3 只候选（严守单票仓位与持仓上限）
5. 输出中文结论：买了什么、卖了什么、为什么、明天怎么办

设置页可开「启动时自动跑一遍 AI 交易」（每天一次）。

## 实时日志窗口

独立「日志」Tab，实时滚动显示：

- AI 每轮推理
- 每次工具调用与返回（`→ paper_buy {"code":"300829"}`）
- 每笔买入/卖出（含价格、股数、盈亏）
- 网络错误与降级信息

支持一键清空、一键复制全部日志。

## 方便买卖的操作

- 买入计划每行有 **「复制」** → 复制「代码 名称 参考价 目标价 止损价」
- 卡片底部 **「复制买入清单」** → 一次复制前 5 只
- 持仓行 **「复制」** → 复制卖出文本
- 个股详情：**「复制代码」** / **「复制下单文本」**
- 粘贴到券商 App 即可下单，不用手抄

## 出 APK

2. Actions → **Build APK** → Run workflow
3. 3~6 分钟后 Artifacts 下载 `app-debug.apk`

或本地 `python3 deploy.py <token>` 一键建仓+上传+构建。

## 安全

- 行情：东方财富 / 新浪财经公开接口
- AI：OpenAI 兼容（默认 DeepSeek）
- API Key 仅存本机 localStorage，不上传
- 结果为量化信号，**不构成投资建议**
